## Title

Coding Evaluation Task Authoring Kit — Python Task Template, Verifier Checklist, and Working CLI

## Short description

Plan and preflight a small Python coding task with a reusable brief, test matrix, verifier review checklist, worked example, and an open-source CLI that checks reference/starter outcomes.

## Product description

Writing a coding task is more than writing a prompt and a few tests. This kit helps you connect the prompt, acceptance criteria, verifier, and known implementations in one reviewable workflow.

### Included

- Python CLI source and install instructions (Python 3.10+).
- `repoeval init` task scaffolding and `repoeval audit` known-outcome preflight.
- Editable task brief worksheet and test coverage matrix.
- Verifier quality checklist and manual review scorecard.
- A complete tag-normalization example with starter, reference, and 18 tests.
- Clear explanations of what the automated audit does and does not establish.

### Good fit for

- People learning to author coding exercises or evaluation tasks.
- Educators and small teams who want a consistent starting structure.
- Reviewers who want to inspect reference and starter behavior before asking for human review.

### Not included

- Cloud execution, a secure sandbox, a hosted evaluation service, or candidate monitoring.
- A claim that a task is novel, fair, comprehensive, or suitable for hiring decisions.
- Personalized review, job placement, or benchmark performance claims.

### Setup

Requires Python 3.10 or later and an internet connection only if dependencies need to be installed. The kit runs locally. RepoEval executes Python code; its timeout does not isolate untrusted code. Use only trusted code or a properly configured sandbox.
